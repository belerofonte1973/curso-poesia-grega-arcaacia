## Glossário de instituições e conceitos

| Termo | Definição |
|-------|-----------|
| **Agora** | Praça pública; centro da pólis |
| **Aulos** | Instrumento de sopro (oboé) |
| **Eisphora** | Imposto extraordinário |
| **Ephestesia** | Revolução política |
| **Hoplita** | Soldado de infantaria pesada |
| **Kithara** | Instrumento de cordas (lira grande) |
| **Kleros** | Lote de terra |
| **Kouros** | Estátua masculina arcaica |
| **Phalanx** | Formação militar hoplita |
| **Pólis** | Cidade-estado grega |
| **Simposio** | Banquete aristocrático |
| **Seisachtheia** | Reforma de Solão: libertação dos endividados |
